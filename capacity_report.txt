HONEST NOTES
  * B1 uses one output per word — a deliberate deviation from production's 6 outputs, required to ask
    "can these two words be told apart at all?". B2 keeps production's output layer and grows only the vocabulary.
  * The word→ALPN pattern (char 3/4-grams → 75 of 685 PNs) is OUR encoding; only the ALPN→KC step is measured.
    A different input encoding moves both ceilings: these numbers bound this pipeline, not "the fly".
  * 1317 surface forms in the corpus fold onto a code that already exists (ş/ı/ğ/ü/ö/ç → ASCII), so they are
    unrepresentable at the input layer no matter how large the mushroom body is.
  * Training is deterministic but the grid is re-trained per N on nested prefixes, so rows are related, not
    independent samples; a single N is one draw, not a distribution.
  * Runtime is dominated by B1 at large N: when the delta rule cannot separate everything it runs to the
    4000-epoch cap, and that is exactly the measurement.
  * The grid stops at N=500 (the Phase 10 request). Beyond it the B1 cost grows ~N² per epoch, so the
    crossing should be re-measured rather than extrapolated — --n takes any sizes the corpus covers (48376 words).
